# Rauha 올인원 로드맵 (2026-11-11, 사용자 요청)

**사용자가 Rauha에게 원하는 것**: VS Code, Apidog(API 클라이언트), Docker Desktop, VS Code 확장 프로그램 여러 개, GitHub Desktop 처럼 백엔드 개발에 필요한 설치 프로그램을 줄이고, Rauha 하나로 개발·운영을 다 하는 것. Docker Desktop 기능도 VS Code 확장처럼 넣어도 좋다.

**정직한 한계**: Docker 엔진(컨테이너를 실제로 돌리는 것)은 Rauha가 대신할 수 없다. 맥에서는 Docker Desktop·Colima·OrbStack·Podman 중 하나가 엔진으로 필요하고, Rauha는 `docker` 명령을 부르는 화면(목록·시작/정지·로그·compose)만 맡는다. 엔진이 없으면 "엔진이 꺼져 있어요" 안내와 설치 링크를 보인다.

## 지키는 원칙
- 새 탭 이름은 짧은 영어 한 단어(왼쪽 막대에서 잘리지 않게 ≤ 6자: API, Docker→"Dock"?, DB). 화면 글은 영어, 채팅·팀 내용만 한국어.
- 비밀(토큰·DB 비밀번호·.env)은 AI·기록·진단에 넘기지 않는다(기존 가림 규칙 재사용).
- 외부 프로그램 호출은 고정 인자 목록만(shell 문자열 조합 금지), 위험 동작은 확인창.
- 맥·윈도우 둘 다, 엔진/도구가 없으면 조용히 실패하지 말고 이유와 설치 링크를 보인다.
